SYSTEM DECISIONS

설계 판단과 통제 기준

이 시스템의 핵심은 분석 항목을 많이 만드는 데 있지 않습니다. 서로 다른 원천과 신호가 어떤 역할을 맡고, 어떤 검증을 통과해야 결과물에 들어가는지를 먼저 고정했습니다.

설계 지점판단 기준통제 방식
데이터 계보별도 수집 시스템과 프로젝트 내부 수집의 역할을 구분원천은 읽기 전용으로 소비하고 분석 저장소와 참조 기준을 분리
신호의 역할점수에 반영할 신호와 설명에만 사용할 신호를 구분지역→생활권→단지→평형 순서와 투자검토 게이트로 후보를 구조화
시간축 검증평균 성능이 실패 구간을 가리지 않도록 확인시점 고정형 워크포워드, 국면별 홀드아웃과 단지·평형 검증
반복 실행입력과 규칙이 달라졌을 때 결과 변화의 이유를 추적실행 기준, 사전 점검, 회귀 비교, 출처·운영 이력과 수동 보정 승인
전달 경계복잡한 분석과 독자가 이해할 설명을 함께 유지판단표·대시보드·보고서·패턴 라이브러리로 목적별 변환
