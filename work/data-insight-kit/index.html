CASE 01 · AI DATA ANALYSIS SYSTEM

사람과 AI가 협업하는 데이터 분석 시스템

데이터는 있지만 분석 질문과 검증 절차를 세우기 어려운 사용자가, AI와 중간 결정을 확인하며 보고서와 대시보드를 완성하도록 만든 분석 키트입니다.

프로젝트
data-insight-kit
목적
질문·분석·검증·전달을 하나의 승인형 흐름으로 연결
결과
8단계 분석 과정, 대시보드·보고서, QA와 공개 배포

OVERVIEW

분석을 자동화하는 것보다, 판단 지점을 설계했습니다

데이터 분석은 코드를 실행하는 것만으로 끝나지 않습니다. 어떤 질문을 다룰지, 데이터 범위가 적절한지, 분석 기준과 화면 구성이 목적에 맞는지 사람이 확인해야 결과를 실제 판단에 사용할 수 있습니다.

data-insight-kit은 AI가 분석과 결과물 초안을 만들고, 사용자가 중요한 방향을 결정한 뒤에만 다음 단계로 진행하도록 구성했습니다.

PROCESS

질문에서 검증된 결과물까지

  1. 01
    목표 설정

    분석 질문, 사용자와 완료 조건을 먼저 정합니다.

  2. 02
    데이터 연결

    사용할 데이터의 범위와 역할을 확인합니다.

  3. 03
    구조 탐색

    분포·누락·관계와 분석 가능한 단위를 파악합니다.

  4. 04
    분석 설계

    질문에 맞는 비교 기준과 검증 방법을 정합니다.

  5. 05
    분석 실행

    승인된 기준 안에서 분석과 후보 비교를 수행합니다.

  6. 06
    화면 제작

    결과를 읽기 쉬운 대시보드와 시각화로 구성합니다.

  7. 07
    품질 검증

    누락·모순·표시 오류와 결과물의 완료 조건을 확인합니다.

  8. 08
    결과 전달

    검증된 대시보드와 분석 보고서를 함께 제공합니다.

HUMAN IN THE LOOP

AI가 만들고, 사람이 방향을 결정합니다

AI의 역할

데이터 구조 탐색, 분석 코드와 차트 구성, 보고서 초안과 반복 검토를 보조합니다.

푸디의 역할

질문, 데이터 범위, 분석 기준, 화면 구성과 결과 수위를 결정하고 검증 기준을 설계합니다.

PUBLIC BASELINE

공개된 구현과 검증 기준

공개 v0.2.2에는 분석 단계, 사용자 확인 지점, 조건부 분석 경로, 대시보드·보고서 템플릿과 QA 기준이 함께 들어 있습니다. 공개 기준선 이후의 로컬 실험과 비공개 실행 결과는 이 사례에 포함하지 않습니다.
