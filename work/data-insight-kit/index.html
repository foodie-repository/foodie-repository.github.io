PUBLIC BASELINE

공개된 구현과 검증 기준

공개 v0.2.2에는 8단계 분석 흐름, 네 번의 사용자 확인, 조건부 분석 경로, 대시보드·보고서 템플릿과 QA 기준이 포함되어 있습니다. 이 사례는 공개 구현과 재현 가능한 구조를 설명하며, 외부 사용자의 시간 절감이나 의사결정 개선 효과는 아직 검증하지 않았습니다. 공개 기준선 이후의 비공개 실행 결과도 포함하지 않습니다.

OVERVIEW

분석을 자동화하는 것보다, 판단 지점을 설계했습니다

데이터 파일이 있어도 무엇을 질문해야 하는지, 어떤 지표와 비교 기준을 사용해야 하는지 결정하기는 쉽지 않습니다. AI가 분석과 시각화를 한 번에 생성하더라도 처음의 질문이나 기준이 잘못되면 그 오류가 대시보드와 보고서까지 이어질 수 있습니다.

data-insight-kit은 AI가 분석과 결과물 초안을 만들고, 사용자가 중요한 방향을 결정한 뒤에만 다음 단계로 진행하도록 구성했습니다.

사람이 확인하는 네 지점

  • 01데이터의 범위와 품질
  • 02분석 질문과 핵심 지표
  • 03대시보드의 구성과 차트
  • 04보고서의 독자·깊이·결론 수위

PROCESS

질문에서 검증된 결과물까지

  1. 01
    목표 설정

    분석 질문, 사용자와 완료 조건을 먼저 정합니다.

  2. 02
    데이터 연결

    사용할 데이터의 범위와 역할을 확인합니다.

  3. 03
    구조 탐색

    분포·누락·관계와 분석 가능한 단위를 파악합니다.

  4. 04
    분석 설계

    질문에 맞는 비교 기준과 검증 방법을 정합니다.

  5. 05
    분석 실행

    승인된 기준 안에서 분석과 후보 비교를 수행합니다.

  6. 06
    화면 제작

    결과를 읽기 쉬운 대시보드와 시각화로 구성합니다.

  7. 07
    품질 검증

    누락·모순·표시 오류와 결과물의 완료 조건을 확인합니다.

  8. 08
    결과 전달

    검증된 대시보드와 분석 보고서를 함께 제공합니다.

HUMAN IN THE LOOP

AI가 만들고, 사람이 방향을 결정합니다

AI의 역할

데이터 구조 탐색, 분석 코드와 차트 구성, 보고서 초안과 반복 검토를 보조합니다.

푸디의 역할

질문, 데이터 범위, 분석 기준, 화면 구성과 결과 수위를 결정하고 검증 기준을 설계합니다.
