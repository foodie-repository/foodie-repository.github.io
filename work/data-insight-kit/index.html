데이터 파일에서 대시보드와 보고서까지, AI와 단계별로 만드는 분석 도구

data-insight-kit은 표 형태의 데이터를 넣으면 AI가 단계마다 사용자의 의도를 확인하면서 분석 보고서와 대시보드를 만드는 공개 분석 도구입니다. Codex와 Claude Code 같은 AI 코딩 도구에 설치해 사용합니다.

WHEN TO USE

이럴 때 씁니다

AI에게 데이터를 주고 “분석해 줘”라고 하면 그럴듯한 차트와 글이 금방 나옵니다. 하지만 처음의 질문이나 기준이 잘못되면 그 오류가 대시보드와 보고서 끝까지 이어집니다. data-insight-kit은 AI가 끝까지 혼자 진행하지 않고, 중요한 지점마다 멈춰서 사용자에게 묻도록 만든 도구입니다.

  • 데이터 파일은 있는데 어떤 분석 질문으로 시작해야 할지 모를 때
  • 대시보드와 보고서를 한 번에 만들되, 중간에 내 의도를 계속 확인받고 싶을 때
  • 단순한 상위 순위표가 아니라 분포, 변화, 차이, 예외, 한계를 함께 보고 싶을 때
  • 회사나 팀의 지표·용어·보고서 기준을 분석에 반복해서 적용하고 싶을 때

특정 업종에 맞춘 도구가 아니어서 표 형태의 데이터라면 같은 방식으로 분석을 시작할 수 있습니다.

HOW IT WORKS

요청 한 줄에서 결과물까지 진행되는 순서

분석은 아래 순서로 진행됩니다. 사용자 확인이라고 표시한 네 단계에서는 AI가 쉬운 요약과 질문을 보여 주고 멈춥니다. 사용자가 실제로 답해야 다음 단계로 넘어갑니다.

  1. 01
    요청과 질문

    “이 데이터로 분석 보고서와 대시보드를 만들어줘”라고 요청하면 AI가 목적과 독자를 먼저 묻습니다.

  2. 02
    데이터 연결과 탐색

    파일을 읽어 행과 열, 범위, 품질을 살펴봅니다.

  3. 03
    데이터 확인사용자 확인

    데이터의 범위와 품질, 분석할 수 있는 것과 없는 것이 맞는지 사용자가 확인합니다.

  4. 04
    분석 방향 확인사용자 확인

    어떤 질문과 지표, 비교 기준으로 볼지 사용자가 정합니다.

  5. 05
    분석과 차트 설계

    정한 방향대로 계산하고 어떤 차트로 보여 줄지 설계합니다.

  6. 06
    대시보드 구성안 확인사용자 확인

    어떤 데이터로 어떤 차트를 만들고 어떤 화면으로 보여 줄지 사용자가 확인합니다.

  7. 07
    대시보드 생성과 점검

    대시보드를 만들고 화면이 제대로 그려졌는지 자동으로 점검합니다.

  8. 08
    보고서 구성안 확인사용자 확인

    보고서의 독자, 깊이, 문체, 결론의 수위를 사용자가 확인합니다.

  9. 09
    보고서 작성과 점검

    보고서를 쓰고 근거가 빠진 곳이 없는지 점검합니다.

각 확인 단계는 완성된 안을 승인만 하는 절차가 아니라 짧은 문답입니다. 예를 들어 데이터 확인 단계에서는 도구가 실제 데이터에서 미리 계산한 “볼 만한 방향” 두세 가지를 결과와 함께 보여 주고, 사용자가 고른 방향이 분석 질문과 비교 기준에 반영됩니다.

ANALYSIS DEPTH

데이터에 맞춰 분석 깊이를 정합니다

분석 방향을 확인하는 단계에서 도구는 데이터와 목적에 맞는 분석 깊이를 추천합니다. 비교할 집단이나 표본 수가 부족해 깊은 분석이 어려우면 자동으로 기본·진단 수준으로 낮추고, 낮춘 이유를 결과물에 기록합니다.

분석 깊이무엇을 하는가
기본 현황 파악무엇이 많고 적은지, 분포가 어떤지 요약합니다.
진단 확인어떤 집단이 두드러지는지, 예외는 무엇인지 확인합니다.
통계적 확인차이나 관계가 우연인지 통계적으로 확인합니다.
패턴 탐색자연스럽게 묶이는 그룹이나 이상치를 찾습니다.
예측 후보 확인예측할 수 있는 대상과 검증 조건을 확인합니다.
실험·효과 검토조치 전후의 변화나 처리 효과를 검토합니다.

OUTPUTS

분석이 끝나면 남는 결과물

대시보드

브라우저에서 바로 열리는 HTML 파일 하나로 만들어집니다. 핵심 지표를 빠르게 공유하는 요약형, 세부 집단과 예외를 살피는 탐색형, 반복 지표를 추적하는 모니터링형 가운데 목적에 맞는 화면을 고릅니다.

분석 보고서

핵심을 정리한 요약 보고서를 만들고, 선택하면 더 자세한 심층 보고서를 함께 작성합니다.

단계별 분석 문서

데이터 점검, 탐색, 분석 질문 정리, 분석 결과가 단계마다 문서로 남아 결론이 어떤 과정에서 나왔는지 다시 확인할 수 있습니다.

자동 점검

대시보드와 보고서는 차트 데이터, 화면 렌더링, 라벨 겹침, 빈 차트, 보고서의 깊이와 근거 누락을 점검하며, 점검을 통과해야 완료로 처리됩니다.

GET STARTED

시작하는 방법

Python 3.11 이상과 Git이 설치된 환경에서 사용합니다. Codex에서는 아래 두 줄로 공개 v0.2.2를 설치합니다.

codex plugin marketplace add foodie-repository/data-insight-kit --ref v0.2.2
codex plugin add data-insight-kit@data-insight-kit

Claude Code에서는 터미널에서 아래 두 줄로 설치합니다.

claude plugin marketplace add foodie-repository/data-insight-kit
claude plugin install data-insight-kit@data-insight-kit

설치한 뒤 계획 모드를 켜고 “이 데이터로 분석 보고서와 대시보드를 만들어줘”라고 요청하면 질문과 함께 분석이 시작됩니다. 분석 결과는 사용자의 컴퓨터에만 저장됩니다.
