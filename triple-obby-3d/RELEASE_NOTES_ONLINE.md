# Triple Obby 3D Online

## Online release

- 3D Color Obby, Lava Tower, and remade Sky Islands
- Floor kill zones on playable maps
- Cracked crumble platforms that disappear and respawn
- 6-character online room codes
- Up to 8 players per room
- Remote player avatars with interpolation/extrapolation
- Host-controlled shared map selection
- Shared crumble block state
- Automatic host handoff
- Server heartbeat recovery for missed map broadcasts
- Camera modes: third person, close, first person, top view
- WASD uses fixed world axes and is independent of camera mode
- Separate camera button plus C keyboard shortcut
- Public invite links and in-game QR rendering
- Online request timeouts and solo fallback behavior

Canonical URL: https://foodie-repository.github.io/triple-obby-3d/
