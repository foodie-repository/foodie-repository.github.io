# Neon Dash V2 — 2026-11-02 복구 개발

기존 `neon-dash/index.html`은 변경하지 않고 `neon-dash-v2/index.html`에 별도 버전을 배포했습니다.

## 기존 프로젝트 유지
- 1단계 Neon Start: 맵/귀신 연출/오디오/기존 AUTO 입력 기록과 지문 유지.
- 맵 편집기, 저장, 맵 코드, 기본 오디오, 난이도 선택, 장치 모드 유지.

## 기능형 블록
- 2단계 Pulse Factory: Bounce Block — 블록 위로 착지 시 자동 강한 반동.
- 3단계 Sky Circuit: Moving Block — 상하로 이동하는 발판, 착지 중 발판 이동량 반영.
- 4단계 Wave Storm: Electric Block — 일정 주기로 활성화되며 접촉 시 사망.
- 5단계 Final Eclipse: Collapse Block — 착지 후 0.32초부터 약 1.35초 붕괴.
- Wave: 누르고 있는 상태 기준 대신, 탭할 때마다 상승/하강 전환. AUTO는 과거 입력 기록의 상승/하강 상태를 그대로 재현하도록 변환.

## 장애물 및 난이도
- 원래 맵 내 블록-블록, 블록-가시, 포털-장애물 겹침 제거.
- AUTO 경로와 충분한 간격을 두고 추가 장애물을 배치한 고밀도 구성.
- 신규 추가 장애물(가시/비행): Pulse Factory 31/18, Sky Circuit 24/84, Wave Storm 18/83, Final Eclipse 19/101.
- 원래 데이터에서 서로 겹친 가시는 최종 버전에서 추가로 정리.

## AUTO
- 공식 2~5단계 기존 AUTO 입력 이벤트를 새로운 맵 구조에 맞게 지문 갱신 및 시뮬레이션 재검증.
- 고정 물리 스텝: 120 Hz.
- 최종 재검증: 2단계 tick 7353, 3단계 tick 8908, 4단계 tick 9531, 5단계 tick 11397에 완주.
- 1단계 원래 지문: `og1-3d76dfff` 유지.
- 기존 UI의 AUTO 입력 방식 유지 (비밀 코드 `뀨`).

## 제한과 확인 사항
- 코드 문법 검사 및 독립 물리 시뮬레이션 수행.
- 실제 모바일 브라우저(터치 입력, GPU 렌더링, 오디오 포함)의 종합 E2E 검증은 미실시.
- 기존 AUTO 입력 기록을 재사용하여 재검증했으며, 네 단계의 신규 수동 녹화본을 제작한 것은 아닙니다.
- 게임 공개 URL: https://foodie-repository.github.io/neon-dash-v2/


## 2026-11-02 추가 업데이트: 중력 반전 · 3단 점프 · 네모 커스터마이징

- **중력 반전 스위치(⇅)**: 큐브가 스위치를 건드리면 중력 방향이 반전됩니다. 중력이 위로 작용할 때는 천장에서 이동하고 점프할 수 있습니다. 두 번째 스위치로 원래 중력으로 복귀합니다.
- **3단 점프 블록(3×)**: 스위치에 닿으면 첫 점프가 발동하고, 공중에서 두 번 더 점프할 수 있습니다. 착지하면 추가 점프 횟수는 초기화됩니다. 연속 점프 시 화면 위쪽 경계에서도 즉사하지 않습니다.
- **맵 제작**: 편집기 팔레트에서 '중력 반전', '3단 점프' 도구를 선택해 자신만의 맵에 배치할 수 있습니다. 커스텀 맵 내 저장 및 맵 코드 직렬화에 두 오브젝트가 포함됩니다.
- **2~5단계**: 각 공식 맵의 앞·뒤 절반에 중력 블록 두 개와 3단 점프 블록 한 개씩 배치했습니다. 총 6개/맵. 일반 경로를 선택해도 진행 가능합니다.
- **네모 꾸미기**: 메인 메뉴에서 네모 색, 테두리, 빛 색, 얼굴 6종을 선택합니다. 변경 사항은 같은 브라우저의 `localStorage`에 보존되고 다른 맵에도 적용됩니다.
- **AUTO 검증**: 수정된 2~5단계의 원래 AUTO 이벤트를 120Hz 물리 시뮬레이션으로 재실행한 결과 각각 tick 7353, 8908, 9531, 11397에 완주. 신규 능력 오브젝트는 선택 경로에 배치하여 AUTO 기존 동선을 유지했습니다.
- **개별 기능 검증**: 추가 공중 점프 2회, 중력 반전 두 번, 천장 착지 및 중력 복귀, 화면 위쪽 점프 경계에서 비사망 확인.
- **QA 제한**: JS 문법/물리 시뮬레이션은 검증했으나 Android 실제 기기에서의 터치/성능/오디오 E2E 검증 및 Pages 배포 전파 확인은 별도 수행해야 합니다.

## 2026-11-03 업데이트: 단계별 누적 기믹 + 중력 반전 천장 바닥

- 단계 1 (Neon Start): 기본 블록, 가시, 점프 패드·링. 기존 구현 유지.
- 단계 2 (Pulse Factory): 1단계의 기본 기능 + 바운스 블록 + 중력 반전 스위치. 이 단계에는 3단 점프 블록을 표시하지 않음.
- 단계 3 (Sky Circuit): 2단계 기능을 유지하고, 움직이는 블록 + 3단 점프 블록 추가.
- 단계 4 (Wave Storm): 3단계까지의 블록을 유지하고, 주기적인 감전 블록 + Wave 모드 추가.
- 단계 5 (Final Eclipse): 4단계까지의 모든 블록에 붕괴 블록 추가.
- 기능형 블록은 기존 맵의 일반 블록을 적절히 보존하면서 독립적인 실물 충돌체로 추가했으며, 두 번째 반복 구간에도 같은 종류를 배치함.
- 중력 반전이 적용되면 플레이어는 y=58의 상단 바닥에 착지할 수 있음. 이 충돌면과 일치하도록 상단을 보라색 바닥으로 렌더링하며, 다시 정상 중력으로 바뀌면 상단 바닥이 사라짐.
- 공식 2–5단계 AUTO 검증(120Hz): 각각 tick 7353, 8908, 9531, 11397 완주. 블록-블록 겹침 0건.
- 검증 범위는 코드 구문과 시뮬레이션까지이며, 실제 브라우저의 그래픽·오디오·터치 종합 E2E 테스트는 별도로 수행해야 함.

## 2026-11-03 추가 패치: 한 갈래 코스 + 비행/Wave 완화 + 바닥 블록 정리

- 공식 맵 1~5단계 모두 바닥 충돌 객체를 **연속된 단일 floor 1개**로 변경. 복잡한 바닥 중첩 및 끊어진 구간 대신 명확한 좌→우 진행 코스를 사용.
- 2~5단계에 기존의 별도 선택형 상단 파워 블록 경로를 제거하고, 마지막에 **중력 반전→천장 이동→중력 복귀**를 일렬로 통과하는 안전한 1,750px 구간을 추가. 3~5단계에는 이 구간에 3단 점프가 이어짐.
- 원래 맵과 기능의 누적 순서는 유지함. 1단계 맵에는 중력/3단 점프를 추가하지 않고, 기존 큐브·비행·Wave를 유지하면서 코스 정리와 난이도 완화를 적용.
- 비행·Wave 통로: 원래 장애물의 높이를 단계별로 약 23~29% 줄이고, 과밀하게 추가된 bonus flight obstacle을 3개 중 1개만 남겨 간격 확보.
- 바닥에 반복되던 불필요한 블록 **총 40개 제거**(1단계 4개, 2단계 18개, 3단계 6개, 4단계 2개, 5단계 10개). AUTO 경로에서 필요한 플랫폼 및 각 단계 고유의 기능형 블록은 유지. 제거 기준은 반복되는 장식/필러 블록이며, 삭제 후 각 스테이지의 AUTO 검증을 재수행.
- 모든 공식 스테이지 120Hz 입력 리플레이 재검증: stage1 tick 13823, stage2 tick 7989, stage3 tick 9548, stage4 tick 10171, stage5 tick 12040 모두 완주(0-based tick). 2~5단계의 중력 전환은 각각 상향/하향 두 차례, 3~5단계의 트리플 점프 블록 1회 발동도 시뮬레이션 확인.
- AUTO replay의 맵 fingerprint는 새 공식 맵 구조를 기준으로 실행 시 다시 계산하며, 입력 이벤트는 기존 저장분을 사용합니다.
- 브라우저 전역 터치/오디오/그래픽 E2E는 아직 검증하지 못했으므로 실제 기기에서 플레이하며 추가 검증 필요.
